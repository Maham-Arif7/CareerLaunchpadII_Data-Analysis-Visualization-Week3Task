# Week 3: Sales Data Analysis
## Overview
This project is the Week 3 task for Sales Data Analysis using Excel. The goal was to build a complete workflow: starting with raw sales data, cleaning and preparing it, applying Excel’s data tools, creating PivotTables, and finally designing an interactive dashboard with slicers and charts.

## Contents of the File
The Excel workbook contains:

### Sheet1 – Sales Data:

Clean dataset with 100+ rows.

Columns: Date, Region, Salesperson, Product, Quantity, Unit Price, Total Sales.

Additional derived fields: Month and Year.

Data validation applied, duplicates removed, and What‑If analysis performed.

### Sheet2 – Insights & Dashboard:

PivotTables summarizing sales by Region, Product, and Salesperson.

Charts: Column (Region), Line (Monthly Trend), Pie (Product).

Slicers for Region, Product, and Salesperson to make the dashboard interactive.

### One‑page written summary of insights.

## Key Features
Data Cleaning & Preparation

Validation rules for Region and Quantity.

Removal of duplicate entries.

Date split into Month and Year for trend analysis.

What‑If Analysis

Goal Seek used to calculate Unit Price needed for $500,000 in Total Sales.

Data Table showing profit changes at +5%, +10%, +15% Unit Price increases.

PivotTables

Total Sales by Region and Product.

Top 3 Salespersons by Total Sales.

Monthly Sales Trend grouped by Date.

Dashboard Visuals

Column Chart: Sales by Region.

Line Chart: Monthly Sales Trend.

Pie Chart: Sales by Product.

Slicers for interactive filtering across all charts.

## Insights Summary
Total Sales: $500,000 after price adjustments (~10% decline from original).

Regional Leader: North region with ≈ $205K.

Top Performer: Sara Khan with ≈ $155K.

Product Drivers: Keyboards ($156K) and Printers ($115K).

Trend: Strong mid‑year growth with peaks in March, May, and October.

Takeaway: Region, salesperson, and product mix drive performance; price adjustments reduced revenue but improved competitiveness.

## How to Use
Open Sheet1 to view the raw dataset and practice data tab tools.

Use Sheet2 to explore PivotTables, charts, and the interactive dashboard.

Apply slicers to filter by Region, Product, or Salesperson — all charts and tables update dynamically.

Read the Insights Summary for a one‑page overview of findings.
